## ¿Qué es la Programación Competitiva?

La **Programación Competitiva** es una disciplina en la que los participantes deben resolver problemas de lógica, matemáticas y algoritmos dentro de un límite de tiempo y memoria estrictos. Su objetivo principal es entrenar el pensamiento analítico, el diseño eficiente de algoritmos y la optimización de código.

---

## Sobre el CSES Problem Set

El **CSES Problem Set** es un conjunto de problemas de programación mantenido por la *Universidad de Helsinki*. Es ampliamente utilizado por la comunidad internacional para aprender y practicar algoritmos clásicos y estructuras de datos, sirviendo como una de las mejores plataformas de entrenamiento para competencias como ICPC o IOI.
